장전 브리핑 HITL — LangGraph 워크플로

graph.py 에서 실제로 컴파일한 그래프입니다. 실선 = 항상 가는 길, 점선 = 조건에 따라 고르는 길.
gate → review(사람 승인 대기, interrupt로 멈춤) → publish(발행) 또는 rejected(반려)

---
config:
  flowchart:
    curve: linear
---
graph TD;
	__start__([
__start__
]):::first
	collect(collect)
	select(select)
	report(report)
	verify(verify)
	gate(gate)
	review(review)
	rejected(rejected)
	publish(publish)
	__end__([
__end__
]):::last
	__start__ --> collect;
	collect --> select;
	gate -.-> publish;
	gate -.-> review;
	report --> verify;
	review -.-> publish;
	review -.-> rejected;
	select -.-> report;
	select -.-> verify;
	verify --> gate;
	publish --> __end__;
	rejected --> __end__;
